## Overview

ERR Pausemenu is a FiveM pause menu built to be **configured rather than replaced**.

The menu, its options, icons, actions, Discord section, patch notes, and visual details can all be shaped around the server using the included configuration.

> **Unlimited options. Your labels. Your icons. Your actions.**

<br>

## Features

**Custom menu options**
Add as many options as you need, with custom labels, icons, links, client actions, and server actions.

**Cinematic camera**
Smooth camera transitions when opening the menu.

**Patch notes**
Keep server updates and announcements directly inside the pause menu.

**Discord section**
Configure the Discord area around your own community.

**UI customization**
Adjust the interface to match the visual identity of your server.

**Lightweight**
Designed to keep unnecessary resource usage low while staying responsive.
